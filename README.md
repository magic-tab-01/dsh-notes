# dsh-notes

DeepSeek Harness（DSH）富文本笔记插件：带左侧栏入口，支持富文本、图片、链接、符号、页面背景、分类与导出。

## 功能

- 富文本：加粗 / 斜体 / 下划线 / 删除线、标题、引用、列表、像素级字号、字体颜色、高亮
- 图片：上传 + 粘贴（自动压缩）
- 链接、符号面板（含最近使用）
- 页面背景（29 种预设 + 自定义颜色）
- 笔记分类（多级、可折叠）
- 标题大纲折叠
- 导出 Markdown / HTML / JSON
- 自动保存到浏览器 localStorage

## 安装

```bash
dsh plugin --profile <profile> add @magic_01/dsh-notes
```

`<profile>` 换成你的 profile 名（网页版通常是 `web`）。
